ACT User Reference

A practical reference for installing the extension, finding its tools, and moving through a StrucEngLib analysis in ANSYS Workbench.

Overview

The ACT extension exposes StrucEngLib workflows within ANSYS Workbench and Mechanical. Use this guide as the entry point for the extension interface; the Usermat reference covers the material model inputs and result quantities in more detail.

Before you begin

Confirm that your ANSYS release is supported and that you can access the extension package described in the getting-started guide.

Installation and loading

  1. Download the current extension package from the project distribution location.
  2. Open the ANSYS extension manager and install the package.
  3. Enable the StrucEngLib extension for the current Workbench project.
  4. Open Mechanical and confirm that the extension tools are available.

For release-specific requirements and the latest package location, see Getting Started.

Workbench interface

Extension commands are grouped around the analysis setup they affect. Select an object in the Mechanical tree before adding a StrucEngLib item so that it is attached to the intended analysis context.

Typical project sequence

  • Prepare geometry, materials, contacts, and the analysis system.
  • Add the required StrucEngLib object from the extension tools.
  • Complete the object properties and resolve any validation messages.
  • Generate or update the analysis data, then solve in Mechanical.
  • Review standard ANSYS results together with extension outputs.

Objects and workflows

Each extension object should document its required parent object, editable properties, generated solver data, and available outputs. The workflow pages provide complete examples for common analysis types.

Troubleshooting

The extension is not visible

Check that the package is installed, enabled for the current project, and compatible with the running ANSYS release. Restart Workbench after changing extension-manager settings.

An object reports incomplete input

Review the selected tree location and all required properties. If the model was changed after the object was created, update its references before solving again.
